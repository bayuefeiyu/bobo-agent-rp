# 可切换创作提示词

源资源和交付材料是两件事。项目全局资源位于 `global-modules/narrative-controls/documents/options/`；导入单卡后位于 `features/narrative-controls/documents/options/`。两处都与普通静态创作资料分开放置。不要把档位正文放进模块 Skill，因为 Skill 会被物化到 Agent 可读环境。

## 导演专用要求

导入 `world-narrative-coordinator` 时同时保留其 hybrid 资源目录、controls.json、独立 prompt-preferences 初始设置和前端区域。详见全局源模块的 [DIRECTOR-CONTROLS.md](../../../../global-modules/world-narrative-coordinator/DIRECTOR-CONTROLS.md)。导演档位源在项目 `global-modules/world-narrative-coordinator/documents/options/` 与卡内 `features/world-narrative-coordinator/documents/options/` 独立存放；它们不进入普通静态资料或正文拨档源。

“主角待遇”默认不追加，初始档按确认方案适配；“其他要求”始终最后，只有默认/自定义两档。默认文档由创作者或转卡者填写，可空；不要将其移入玩家自定义字段，也不要把玩家自定义覆盖回默认文档。所有档位和归属标记完整保留，只在运行时过滤。

未标记内容发给 controls.delivery.agents 中全部导演；独占行 `<!-- director-only: Agent-ID, Agent-ID -->` 与 `<!-- /director-only -->` 包围专用段落。按原顺序排除其他 Agent 的专用块，不把通用内容集中前置。标记不嵌套，引用真实 Agent ID；改名或新增 Agent 时同步接收范围与文档标记。公共运行时直接把本次选中、过滤的内容加入对应 Agent 提示词，不增加逐节点分发配置，不导出给正文或检索 Agent。

转卡须使用支持该提示词装配的公共运行时，并验证普通调用、团队成员、穿插顺序、默认空文本、自定义替换、末项排序及未选内容隔离。选中要求的运行快照按原 Agent 提示词层交付，不赋予新的消息角色、任务阶段或数据权限。

## 转卡处理

- 先按全局模块选择流程确认是否导入“正文”模块。选择它就导入 controls.json 明确登记项目的全部档位，不再逐条询问是否保留某个未选项。
- 保留每档原文、来源及宏语义，明确每个项目的初始选择；叙事节奏、抢话方式出厂默认“不追加”，保留原卡创作基础。最后一档“自定义”由前端提供，不需要虚构自定义源文件。
- 正文字数四档为800以内/800-1500/1500以上/自定义；语言两档为中文/自定义；扩写三档为扩写/部分扩写/续写（allowCustom=false）。三项均无“不追加”，初始800-1500/中文/部分扩写。沿用模块的夏瑾系列源文及来源说明，不自行扩充预设内容。它们已从正文任务及旧 task-defaults 中移出；导入本模块时不能再给正文节点、Agent 或固定静态资料追加这三项的旧副本。原卡有相应固定要求时在转换方案中明确迁入选项及初始档；未导入模块时按确认方案保留原卡要求，不能静默丢弃。
- 正文“其他要求”始终是全部拨档最后一项，只提供默认/自定义两档，初始选默认。`documents/options/other-requirements/default.md` 由创作者或转卡者填写，可留空；玩家自定义独立保存，切换不覆盖默认文档或清除草稿。选中内容追加到前面所选正文要求之后，并入同一份普通静态《创作要求》。新增常规项目时保留本项 last=true。
- 互斥关系来自明确登记或用户确认，不能凭目录、文件名、排序推断。并列的非互斥模板继续按普通静态资料流程选择、分类和交付。
- 若原卡的规则拟改为可切换项目，方案需列明原位置、完整选项、默认档位和影响；确认后从固定提示词、普通资料库及其他 Agent 可读重复位置移除对应副本。保留完整溯源，不能静默删除原卡要求。
- 不把所有档位导入普通 card-context-library；不在 foundation、Agent 提示词或普通文档里留下另一档内容。目录摘要也不要列出未选档位及其含义。

## 工作流接入

在普通静态资料导出之后、正文创作之前插入同步调用 `narrative-controls/compose-context`，传入 static-context 目录；它返回包含已选《创作要求》的普通静态资料目录。标准和高级记忆工作流模板提供 prepare-creative-context 节点。输出保持原静态资料的目录索引描述和工作阶段，正文 Agent 仅接收这份组合后的目录。

正文 Agent、入口工作流与准备脚本现在共同属于正文模块。使用替代正文模块时，按确认方案在替代模块内实现或修剪可切换要求接入，并同步 dependsOn、context.fromNodes 与产物声明；不能将正文组件摊平到卡片根目录。导入当前模块时不能跳过组合或额外把原目录交付给正文 Agent。不要为了选择功能给正文 Agent 增加设置查询、编辑权限或可调用源资源导出工作流。

生效文件与普通创作准则同级，继续使用普通静态资料的读取条件，不添加“覆盖所有要求”“最高优先级”等声明。源档原文本身包含的强调属于来源语义，保留它不能被解释为模块机制自动提权。

前端设置属于单个聊天，统一事务保存并校验 revision。自定义草稿在切回预设时保留，只有选择自定义时才进入组合结果。每次正文运行使用冻结设置；新保存值用于下一次生成，历史正文和既有记忆不被重写。

## 验证

检查未选项及未启用的自定义草稿不存在于正文工作区、DOCUMENTS.md、固定提示词和 Agent 可查询视图。验证切换组合、自定义空文本、非法档位、重启保存、多个聊天独立、并发 revision 冲突及删除剧情后缀后设置仍保留。禁止遍历源资源或交付整个模块目录作为替代实现。
