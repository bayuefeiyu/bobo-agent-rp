# 静态资料模板预设

本文件允许创作者提前记录部分静态资料模板通常在什么时候使用。转卡时，只有用户实际选中的材料才会触发对应预设；转卡 Agent 会询问是否沿用，用户可以接受、修改或忽略。

预设使用自然语言描述，不需要手写卡片目录中的 `readPolicy`、`appliesAt`、`readWhen`、选择组或工作流字段。转卡 Agent 在结合原卡资料、目标 Agent 和实际工作流检查后，把确认的意图转换成卡片配置及必要的工作区资料提醒。

## 正文创作指导

# 备注
同一项只选中部分材料时，预设只应用于被选中的材料。路径不存在或指向目录时，转卡 Agent 应报告问题，不猜测替代文件。预设不会自动选择材料，也不覆盖本次转卡中用户给出的新要求。

本文件是模板目录说明，不属于可选静态资料，不复制进卡片。
