# 工作流新执行与正文尝试

## 公共边界

重新执行的最小单位是完整 Workflow v4。失败节点 retry、模型替换和外部提交 recovery 恢复原执行，不创建正文候选。新执行分配独立 executionId、空节点工作区和冻结资料版本；不清空原目录、不覆盖原调用者的导出文件。

默认只允许最新回合启动、重新执行或采用候选。开始下一回合即锁定上一回合选择；旧执行可按已有权限完成原任务，不得改绑到新尝试。删除后缀时按**执行发生回合**回溯贡献，包含后来维护过的旧记录；剩余最新回合重新开放候选。开场仍是第0回合，暂不提供开场重生成按钮。

Workflow 可选声明 `executionPolicy: { enabled: true, allowHistoricalWrites: false }`，也是默认值。`enabled: false` 用于不能独立重跑的生命周期/发布步骤；重做时重跑负责完整核对的上层工作流。`allowHistoricalWrites: true` 允许**本轮执行**维护旧绑定档案，不开放旧轮正文重生成。能力、预算、修订保护和写锁仍有效；作者应解释历史写入需要。

公共能力不要求为每个工作流提供按钮。`POST /api/workflow-runs/<runId>/reexecute` 接受可选安全 `executionId`。相同身份可重放，不同输入复用身份会冲突。正文使用下述专用入口。

## 数据与资料引入

集合默认 `executionScope: "story"`。记录、修订、关系、摘要、覆盖范围和游标进入所属执行版本，各模块不必自行实现候选档案存储。只有独立剧情选择的用户偏好可显式声明 `executionScope: "session"`：修改即时生效，不随切换/删除回滚；执行读取仍冻结，前端展示读取最新设置。

新执行读取当前授权资料，去掉被替换执行自身贡献。子调用继承调用点的冻结资料与已完成因果批次，不自动引入并行兄弟未汇合成果。子调用去重包含父 executionId，不能跨尝试复用旧子成果。精确 `moduleAccess`、文档引入、声明输出和 `workspaceHandoff` 规则继续适用；不扫描整个模块/节点目录。

`workflow/executions.json` 保存执行与选择；`workflow/execution-states/` 按内容指纹共享不可变记录版本和集合引用，避免复制整个运行目录。成功采用的成果进入正式集合、索引和转录，采用清单与正式数据共用事务日志。替换核对原贡献及当前记录；冲突则保留原正式状态、明确失败。缺失成果保持缺失，不能借用其他尝试的图片、事件、归档。

区分 executionId、正文 attemptId、执行发生回合、记录绑定剧情回合，以及实际读取的消息修订/批次/文档版本。批次去重包含 executionId，来源回执保留原身份。过程记录与非采用/失败成果用于调试，不进入下一轮正式输入。

## 正文尝试与视图

首次生成已有 attemptId，等于前台根 executionId。再次生成复用玩家输入和回合，不追加玩家楼层。子工作流、后续触发和手动附加成果继承 attemptId。模型生成来源保留；手改在同尝试内递增 revision，变更 provenance 标记用户。

`GET /api/narrative-attempts` 返回清单与选择 revision；`POST .../regenerate` 创建候选；`POST .../preview` 指定 attemptId（null 返回已采用版本）；`POST .../<attemptId>/adopt` 必须提供清单 expectedRevision；`PUT .../<attemptId>` 提交手改；`GET .../<attemptId>/history` 按预算读取修订。

主正文区预览保留尝试，关联模块与图片读取同一尝试的展示视图。预览不改变正式转录；继续下一轮或启动模块工作前需返回或采用。`messages.jsonl` 始终是已采用正文的派生转录。仅最新回合完整候选可采用；必要后台任务使用既有 `blockNextTurnUntilReady` 声明。正文和已有对应成果一起切换；其他尝试保留，停止继续扩展，迟到结果留在原执行。进入下一轮锁定而不删除候选。

**用户手改例外：**正文即时保留修订，相关既有成果保留真实旧来源；不强制失效、核对、重新归档或阻止续写。用户承担语义变化后果。依赖追踪不触发无界递归自动重算。

## 模块作者约定

内部档案使用统一数据服务，临时产物使用声明工作区。记忆归档的记录、旧记录修订、关系、摘要、覆盖范围/游标全部受管，保留原归档节奏与受保护窗口。前端取当前展示视图，下一轮只引入已采用视图。

影响下一轮的平行事件、状态更新，建议安排在上一轮结束，并声明必要完成约束。本轮正文之前的更新必须明确定义依赖与冲突处理，不能替换正文已经读取的资料版本。

外部副作用不能撤回：生图新执行创建新 operationId，恢复原提交沿用 promptId。ComfyUI 衍生图与恢复亦走模块工作流；取消后外部服务器可能仍完成，回调受原 executionId 限制。

这是受管 API 的保证。可信代码自行写目录或调用外部服务不会自动获得回滚能力；作者必须使用受管集合、工作区与服务。已安装卡、旧会话不自动升级/迁移；旧正文没有对应运行信息时不能伪造生成尝试。

非采用执行禁止继续扩展普通工作流。引擎登记的 terminalFinalizer 可以完成原执行的私有清理，仍不传播到已采用状态；模块不能把这一生命周期例外作为新任务入口。
