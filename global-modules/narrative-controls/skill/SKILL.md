# 正文创作要求

本模块为正文准备本次生效的创作准则。交付的《创作要求》与同一资料目录中的其他创作准则处于同级；按该目录的普通读取规则使用，不因模块来源而提高优先级。

阅读当前任务实际交付的资料即可。前端设置和源资源由代码管理，本模块不向创作 Agent 提供查询或修改设置的工具，也不要求 Agent 自行选择档位。
