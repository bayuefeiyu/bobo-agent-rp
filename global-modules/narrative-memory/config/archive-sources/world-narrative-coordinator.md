# 世界叙事统筹归档来源说明

这里的每一条 `director.archive-handoff` 都已经由导演确认需要归档。不要重新判断其是否重要，也不要把它降级为待观察候选。

- 按 `recordKind` 映射为实体、关系、事件或认知记录。
- 按 `intent` 执行新增/更新、纠正或撤回，并使用 `dedupeKey` 去重。
- `content` 是归档业务内容；`knowledgeScope` 是强制的知情范围，二者都必须保留其语义。
- 对事件与认知，保持其类型差异，不要把角色认知改写为客观事实。
- 不从交接以外推测导演的私有计划、设计来源、置信度或未来情节。
- 内容格式或引用不合法时明确报错，不要自行补造缺失事实。

来源捕获成功后，由确定性确认步骤把对应交接标记为 `captured` 并写入 `sourceCaptureId`；归档 Agent 不直接修改导演模块。
