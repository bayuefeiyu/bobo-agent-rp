# 模板与格式化

`templates/registry.json`是唯一模板注册表。不要通过扫描目录发现模板。每个模板独立保存，便于创作者修改或导入自制模板。

模板只定义记录内容的章节、推荐字段、摘要限制和可筛选面，不能授予工具、数据权限、工作流权限或代码执行能力。

默认模板固定一级章节顺序。二级字段是推荐项而不是封闭 Schema：有内容就按 `字段: 值` 保存，没有内容就省略；与一级章节语义一致的新字段可以增加。需要新增一级章节时，应注册 custom 模板。

格式化严格保留 JSON 结构：标量显示为字段，数组显示为 YAML 列表，嵌套对象继续缩进。若记录只保存简化别名数组，就显示一行别名；若 custom 模板在内容中保存带类型的称谓对象，就按对象原结构显示。代码不得猜测“化名”“昵称”或生成解释性文本。

摘要是目录检索用的短索引，不是正文概述。长度采用软限制：实体30、关系30、知情群体25、事件45、认知40、事件摘要50。超过限制仍可提交，由代码设置 `summaryOverLimit: true`，并在下一次正常归档中列入缩减任务。

实体模板的 `filterFacets` 把筛选名映射到 `sections` 中的确定路径。代码生成 `derivedFacets`；Agent不重复填写。只做确定性值规范化，不把“男性”“男修”“公子”自动归为同义值。

模板版本变化不会自动迁移旧记录。缺失模板时前端仍可用通用JSON查看，但自动归档或维护应明确失败，等待恢复模板或执行经用户确认的迁移。
