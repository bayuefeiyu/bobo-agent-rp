# 记录语义

## 实体

实体类型为 `generic`、`character`、`location`、`faction`、`item`、`ability`、`species`、`concept`。默认模板固定一级章节，二级字段只是推荐项；内容应保存在 `sections` 中。`templateMode: custom` 表示该实体使用独立模板，不是身份唯一性标志。

实体可以有多个信息块。每块独立声明：

- `common`：一般世界内角色可以知道；
- `restricted`：只允许列出的实体或知情群体知道；
- `undiscovered`：已有作者设定，但故事内当前无人知道；
- `unclassified`：知情范围尚未确认，创作时谨慎处理。

`unclassified`只以“知情范围尚未确认”标题显示，代码不生成“是否被他人发现尚未整理”等解释性句子。

角色的特殊态度只在设定或扮演中明显、稳定表现时记录。一次情绪或单次选择不够；避免归档与创作相互强化，令人物逐渐刻板化。

知名度放在实体基本信息中，包含总体程度、描述和可选限定群体 ID。没有合适群体时限定留空，不为知名度专门制造群体。

## 关系

只保存脱离单个事件后仍然成立的关系。一次交易、同行、临时联盟、遗迹内共同进退等留在事件中。单方面特殊态度留在角色实体中；双方对关系的不同理解分别建立认知。

关系使用与实体相同的信息控制方式，不使用数值化信任或关系强度轴。

## 事件

事件的长短取决于时间、空间、行动和目的是否形成明显段落，不取决于正文轮数。玩家角色或主角参与的正文剧情必须归档；可以按信息密度决定详略和拆分。幕后或平行内容只有较特殊、非日常、值得准确复现时才建立事件。

状态只有 `ongoing` 和 `completed`。使用 `precedingEventIds` 串接前置事件；不维护 `followingEventIds`，避免创建新事件时回写旧记录。

## 认知

一条认知只保存一个原子主张，不使用“误解”字段，也不预先判定真假。认知和传闻共用同一类型：知情范围与传播阶段共同表现它是少数认知、刚出现的消息还是广泛传闻。

传播阶段：

- `sealed`：封闭在极少数知情者之间；
- `selective`：有选择地告知；
- `incidental`：零散、偶然扩散；
- `active`：正在主动传播；
- `broadcast`：公开或广泛传播；
- `unclassified`：传播方式尚未确认。

传播阶段不会自动增加知情人。主张内容改变时新建记录并使用 `precedingCognitionIds`；只改变知情范围或传播状态时修订原记录。

## 知情群体

群体有稳定 `name`，创作视图用它显示“紫霄派修士知情”。排除项逐一显示为“林月、丹堂除外”，不设置排除项统称。

- `dynamic`：表示当前成员，角色加入或离开后应及时更新。
- `fixed`：表示某个历史时点的成员范围，后来加入者不会自动知道旧秘密；但新登场角色若设定上本来就是当时的旧成员，可以显式补入。

群体可以嵌套。排除优先，重复成员去重，循环和自引用无效。fixed群体引用dynamic群体时，创建或修订时必须展开为当时的实体ID并保存到 `resolvedMemberIds`，避免未来成员继承旧消息。

## 事件摘要

摘要只合并已经完成、语义上属于同一段剧情的有效事件或摘要。`sourceEntryIds`保存本次直接输入；`coveredEventIds`保存展开后的全部原始事件；`precedingSummaryIds`保存被替代摘要。原始记录从不删除。

有效事件目录排除已被摘要覆盖的原始事件和已被新摘要取代的旧摘要。查看摘要时直接返回全部叶事件，不建立多层展开目录。
