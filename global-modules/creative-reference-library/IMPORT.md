# 创作参考资料库

复制本模块代码并将module.json登记到卡manifest.feature_modules；调用节点精确声明workflowCalls，按需调用。公共宿主与校验器需支持模块v8；已有v7模块继续兼容。

本模块依赖 Node.js 24.14.0+。卡打包器只复制独立核心代码，不复制用户资料。用户级绑定通过配置面板的资料库设置保存，多张卡共用；模型仍在普通Agent/模型配置中选择。不要添加会话占位collection。

资料转换与CLI见 packages/creative-reference-library/README.md。禁止把社区正文、私有路径、索引或维护记录复制进模块或卡包。

## 默认接入

转卡选用正文创作模块或深度导演时，默认配套本模块，并在方案中展示；用户可明确不引入。仅提供 `creative-reference-library/search-units`（b），调用绑定为 `maxCalls: 1`、`fixedArguments: {includeSemanticCandidates: false}`；调用者可提供正常的关键词、上下文和预算参数，不能覆盖固定的语义开关。a、c 保留在本模块内，但不默认授权给这些调用者。

正文在已有资料和前置导演指导返回后、具体情节设计前调用一次；标准/高级记忆、单人/协作团队使用相同位置，团队由共创者调用，全体共享一次。深度导演在阅读冻结剧情、作者资料和记忆后、长期分支与题材设计前调用一次；会议版由 `creative-reference` 助理在讨论早期执行，全体共享一次和返回资料。相关源工作流与阶段提示词已携带默认接线，转卡须保留。

其他模块和日常导演暂不增加调用。未绑定或文本索引未就绪时，入口不开放，提示词跳过检索；空结果正常继续。返回 document-set 的资料仅供参考，使用与改编自由，不自动成为剧情事实或强制约束。用户资料绑定仍通过用户级配置完成，转卡不读取或复制资料库。
