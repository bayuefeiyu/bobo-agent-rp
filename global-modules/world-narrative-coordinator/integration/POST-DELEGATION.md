# 后置委托节点生成规则

只有卡片创作者为当前卡明确配置了正文后置创作模块时，才启用相应分支；没有配置或后置导演本轮决定不启动时，不产生该创作模型调用。

近场与广域模块由后置导演第一次Agent调用直接输出语义委托，运行时代为补充技术ID；创作者仍决定允许委托哪些模块及其卡级约束：

- 读取 `turn-brief-current`，并按目标模块对应的发布清单调用 `materialize-guidance`；
- `workflowCalls` 只列创作者为这张卡预定义的模块工作流及所需组装器；
- 何时调用、调用哪一个、任务内容由创作者的卡级提示决定，模块本身不规定固定任务表；
- 同时传递事实边界、信息披露范围、节奏烈度、完成边界、失败处理和回报要求；
- 委托目标生成的内容按其自身模块规则落地，导演默认没有事后挑选哪些事实算数的权力；仅当创作者明确配置审核权时例外；
- 两个候选只生成文档，不立即写事实；等待全部候选后，由同一后置工作流中的第二次导演Agent调用统一审核。
- 统审只处理硬性冲突和明显逻辑硬伤，优先级默认是既有事实与正文 > 广域 > 近场；修改必须返回完整稿，不能返回模糊修订指令。
- 通过审核后由各模块的无Agent发布工作流并行写入；此后即为事实，后续节点失败不会自动回滚。

该节点仍属于阻塞型 `director-post-turn`，因此其必要委托完成前不会接受下一轮玩家输入。
