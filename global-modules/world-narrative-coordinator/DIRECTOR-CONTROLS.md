# 导演拨档要求

导演模块是 hybrid 包。全部档位源保存在 `documents/options/`，与普通静态资料、正文拨档资源和基础 Agent 提示词分开。`controls.json` 定义项目、档位文档及接收这些要求的导演 Agent ID；它不是节点或团队成员分发配置。`catalog.json` 保存完整文档的资源目录。

## 项目与默认值

“主角待遇”提供不追加、普通角色、主角优待、主角承压、自定义五档。初始选“不追加”，沿用原卡要求；将来可按确认的转换方案设置初始档位。

“其他要求”固定为最后一个项目，`last: true` 保证以后新增的常规项目排在它前面。它只有默认、自定义两档，使用 `allowNone: false`；默认文档 `documents/options/other-requirements/default.md` 由创作者或转卡者填写，允许留空。玩家选择自定义只替换这一项，其他项目继续生效。未选的玩家草稿独立保留。

新增项目时同步 controls、catalog、preferences schema 和初始选择；不得从同目录推断互斥关系。默认档原文随卡包保留，不复制进会话设置；会话只保存档位 ID 与玩家自定义文本。

## Agent 归属标记

未标注的文字提供给 `delivery.agents` 中全部导演 Agent。专用段落使用完整、独占一行的成对注释：

```markdown
通用第一段。

<!-- director-only: world-narrative-daily-director -->
日常导演专用段。
<!-- /director-only -->

通用第二段。

<!-- director-only: world-narrative-deep-director, world-narrative-team-leader -->
两个指定 Agent 共用的段落。
<!-- /director-only -->

通用第三段。
```

组合时按文档顺序保留通用内容与当前 Agent 的专用块，排除其他专用块并去掉标记。不会将所有通用段集中到前面。多个项目按界面顺序组合，“其他要求”最后追加，位置不赋予额外优先级。

一个文档可重复出现专用块，一个块可列多个真实 Agent ID；块不能嵌套。未知/重复 Agent ID、缺失结束标记或不完整标记会报告文档与行号。标记在 Markdown 代码围栏内也生效；需要展示字面示例时使用转义或 HTML 实体。玩家自定义沿用同一格式，普通文本即可发送给全部导演。

归属跟随 Agent 身份。同一个日常导演用于前置或后置任务时收到相同专用内容，共用专家 Agent 的团队成员收到相同专用段。新增或改名导演 Agent 时同步 `delivery.agents` 和相关标记；文档标记不能扩展接收范围，也不改变已有节点职责或数据权限。

## 提示词装配与信息边界

公共运行时在工作流开始时读取冻结的 `director.prompt-preferences`，只组合选中文档与当前选中的自定义文本，保存本次运行的提示词快照。普通 Agent 调用和团队成员调用按其 Agent ID 过滤快照，以普通文本追加到该 Agent 原有提示词层；正文 Agent、记忆检索 Agent 和代码节点不接收这些导演要求。角色/阶段标记作为普通内容处理，不能改变消息角色或任务阶段。

源文档与快照不进入导演的共享资料目录，不进入正文静态资料库，不作为普通指导文档导出。模块 Skill、基础 Agent promptFile 和工作流节点也不承载全部档位。导演按现有职责把需要下发的要求转化为有依据的具体安排，通过原有指导频道交付；避免把幕后策略或档位原文写进对外指导。

`prompt-preferences` 是独立的小型 settings 快照，只提供前端读取/更新权限；公共提示词装配器借助前端声明的读取能力取值，不给 Agent 添加查询该集合的 moduleAccess。设置更新使用统一事务与 expectedRevision，绑定 turn=0，删除故事后缀不撤销玩家设置。新聊天使用卡片初始选择。

保存后从下一次相关导演运行生效。正在运行和恢复的工作流沿用启动时的要求，团队共享同一快照；下一次导演运行核对旧计划、旧报告与旧指导是否仍适用。切换不会自动改写已发生剧情或安排一次新的推演。

## 导入与验证

转换时完整复制 controls、catalog、documents、schema 和 initial snapshot，并注册 hybrid 模块；不得只保留初始选中档。选择使用已有导演功能就同时保留这项前端能力。使用支持 Agent 提示词装配的本项目运行时，导入不会自动更新旧卡或会话。

需验证穿插顺序、多个接收者、未知/嵌套/未闭合标记、普通文本、默认空内容、自定义替换及草稿保留、末项固定、聊天持久化、修订冲突、冻结运行、团队成员过滤、姓名宏及正文/检索 Agent 不接收导演要求。
