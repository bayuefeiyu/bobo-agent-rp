# 近场叙事模块

本模块拥有主线当前地点及周边、暂时位于玩家角色视野之外的正式故事。候选不是事实；只有经上层批准并由 `publish-reviewed-story` 成功发布的故事才是世界事实、前端内容和归档来源。

每次候选调用只写一篇。调用方必须给出 `action`、指定场景、`notAfter`，续写或收束时还要给出 `seriesId`。故事起点由创作 Agent依据正文与系列时间自行选择，不得晚于 `notAfter`。

正式故事追加发布，正常工作流不修改或删除旧故事。高级用户可从前端直接打开权威 JSONL 分区自行 DIY；这会绕过 revision、索引、归档和一致性保障，模块不承担修复责任。

归档提示：正式故事中叙事明确展示的行动属于世界事实；角色言论、传闻、回忆、内心活动和认知必须分别建模并确定实际知情范围。玩家能在前端阅读不代表玩家角色知情。
